# PlateKeyFob Frontend

Интерактивное веб-приложение для заказа кастомных 3D-брелоков автомобильных номеров Кыргызстана (PlateKeyFob).

Приложение позволяет клиентам создавать реалистичный 3D-просмотр брелока госномера Кыргызской Республики в реальном времени, настраивать оборотную сторону (логотипы авто, номер телефона, кастомный текст), оформлять заказ и отслеживать его статус.

---

## 🛠 Технологический стек

- **Фреймворк:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Сборщик:** [Vite](https://vitejs.dev/)
- **3D-визуализация:** [Three.js](https://threejs.org/) (интерактивный 3D-рендеринг брелока, освещение, тени, материалы)
- **Иконки:** [Lucide React](https://lucide.dev/)
- **Эффекты:** [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Стили:** Vanilla CSS (Glassmorphism, адаптивная верстка, анимации)

---

## 🚀 Основные возможности

1. **Интерактивный 3D & 2D Конструктор:**
   - Полное трехмерное отображение брелока с вращением и возможностью приближения/отдаления.
   - Выбор региона КР (01 - Бишкек, 02 - Ош, 08 - Чуй и др.).
   - Кастомизация символов госномера и серии.
   - Настройка оборотной стороны брелока:
     - Выбор автомобильного логотипа (Toyota, Lexus, BMW, Mercedes, Audi, Honda, Hyundai, Kia и др.).
     - Нанесение номера телефона или индивидуального текста/пожелания.
   - Переключение между 3D и 2D режимами предпросмотра.
2. **Оформление и Оплата:**
   - Корзина и оформление заказа в удобном модальном окне (`CheckoutModal`).
   - Автозаполнение данных пользователя.
   - Выбор способа доставки по Бишкеку и регионам Кыргызстана.
3. **Личный Кабинет и Трекинг:**
   - Модальное окно авторизации (поддержка Google, Telegram и логин/пароль).
   - Просмотр истории собственных заказов (`MyOrdersPage`).
   - Отслеживание статуса доставки по уникальному трек-коду (`OrderTrackingPage`).
4. **Административная Панель:**
   - Управление поступившими заказами в реальном времени.
   - Обновление статусов заказов.
   - Экспорт спецификаций моделей для 3D-печати (слайсеры BambuStudio и т.д.).

## ⚙️ Переменные окружения (`.env`)

Создайте файл `.env` в корне `PlateKeyFobFrontend` на основе `.env.example`:

```env
VITE_GOOGLE_CLIENT_ID=your_google_client_id
VITE_TELEGRAM_BOT_NAME=your_telegram_bot_name
```

| Переменная | Описание |
| :--- | :--- |
| `VITE_GOOGLE_CLIENT_ID` | Client ID для авторизации через Google OAuth. |
| `VITE_TELEGRAM_BOT_NAME` | Имя Telegram бота для входа через Telegram Widget. |

## 🚦 Инструкция по запуску

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу: `http://localhost:5173` (по умолчанию Vite).

### 3. Сборка для продакшена
```bash
npm run build
```
Готовые статические файлы будут скомпилированы в папку `dist/`.

### 4. Предпросмотр продакшен-сборки
```bash
npm run preview
```
